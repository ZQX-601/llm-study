# 未来 12 周路线（从当前进度接续）

这是初版学习路线，按每周约 28 小时估算：6 天学习和练习，1 天复习、补缺与总结。每周根据代码与实验的真实结果调整，不按日历机械推进。既有 `LEARNING_PLAN.md` 保留为完整主题地图。

| 周 | 主线与岗位重点 | 必交证据 |
| --- | --- | --- |
| 1 | 完成 GRPO rollout/trainer、权重同步、staleness；核查教学代码 | 一份数据流追踪、一个缺陷修复或代码题、阶段口头验收 |
| 2 | SFT 数据构建、切分、污染检查；LoRA/QLoRA 环境和基线 | 数据合同、可运行微调脚本、训练/验证基线 |
| 3 | SFT/LoRA/QLoRA 实验、误差分析；DPO 数据与目标 | 至少一组可复现实验与对照报告 |
| 4 | GRPO 最小真实训练；PPO/GRPO 选型与奖励诊断 | 运行记录、reward/KL/clipfrac 等曲线或表格、失败案例 |
| 5 | 预训练数据管线、Tokenizer、训练目标、优化器与小模型训练 | 小规模预训练实验、loss 曲线、数据与评估说明 |
| 6 | MoE、注意力变体、位置编码、长上下文；架构对照 | 组件级代码剖析、设计取舍文档、可运行局部复现 |
| 7 | 分布式训练基础、混合精度、显存/吞吐、推理优化 | 配置/瓶颈分析和一项可测的性能对照 |
| 8 | Kimi K3、DeepSeek V4.1 等前沿论文专题 | 官方来源导读、与基线对照、已验证/待核实清单 |
| 9 | RAG 数据、检索、重排、生成与评估 | 可复现 RAG 小项目及离线评测 |
| 10 | MCP、工具调用、单 Agent、错误恢复与可观测性 | 带工具的 Agent 原型和失败案例测试 |
| 11 | 记忆管理、Agent RL、多 Agent 协作 | 记忆策略对照和一个 Agent 训练/评估设计或小实验 |
| 12 | 综合项目、技术复盘和面试准备 | 项目 README、复现实验、架构说明、岗位题库与薄弱点清单 |

## 每周节奏

- 每天默认约 2 小时原理/论文和约 2 小时代码/实验/检测；按当天任务微调。
- 每周选择 1 篇与主线相关的前沿论文或技术报告。先看官方摘要和关键图表，再追核心公式/源码，最后回答其工作场景与局限。
- 周末回顾岗位必备知识和本周代码证据，更新 `STATE.md` 中的薄弱点及复习队列。
- 云计算只用于本地 8 GB 显存确实不合适的实验。租用前明确模型、数据、预计时长、费用上限和验收指标；实验后保存结果并关闭资源。

## 阶段通过标准

- `岗位必备`：能解释原因、读懂关键代码、独立完成至少一个可复现实验或实现，并解释指标异常。
- `需要掌握`：能对比方法、定位常见错误，完成代码级练习或小实验。
- `前沿扩展`：能从一手资料说明动机、核心机制、代价和未核实部分；除非岗位需要，不要求复现整套大模型。
